## 💼 AlyxIA Solutions — What I'm building

**AlyxIA** is a local AI solution designed for SMEs, focused on data sovereignty and confidentiality.

🎯 **My mission**: architect and deploy a complete AI infrastructure — from local LLM inference to documentary RAG — without mandatory reliance on foreign cloud providers.

### AlyxIA Tech Stack

- **Local LLM inference**: Qwen 3 30B served via **vLLM** on a dedicated GPU server (PGX) running Linux
- **Hybrid routing**: local (Qwen) / cloud (Claude API) based on data sensitivity
- **Document RAG**: ChromaDB, pgvector, multilingual embeddings
- **Backend**: FastAPI (Python) as a proxy, PHP for the main website
- **Database**: Supabase / PostgreSQL
- **Frontend**: multilingual chat interface (FR/EN)
- **Security**: PII anonymization, sensitivity classification, nLPD/GDPR compliance
